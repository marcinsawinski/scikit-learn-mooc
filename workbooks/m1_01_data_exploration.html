📒 Workbook M1.01 — Who earns more than $10 an hour?#

In the lab we explored the adult census dataset together. In this workbook you repeat the same steps on your own with a new dataset, and go a bit further.

How this workbook works

  • The code is written for you. You do not need to write code, but you need to understand every step.

  • Every ____ is a gap. Fill it in with the value asked for in the text above the cell. The notebook stops at the first gap you have not filled, so “Run all” will not get you to the end. The error NameError: name '____' is not defined means: a gap is still empty.

  • check(...) tells you whether your value is right (✅) or stops with a hint (❌).

  • commit(...) records a prediction before you see the result. Be honest: a wrong prediction costs nothing, it is how you learn.

  • Questions marked 🧠 Think are not checked here. You will need the answers for the Moodle quiz and for the discussion at the start of the next lab.

def _normalize(value):
    if isinstance(value, float) and value.is_integer():
        value = int(value)
    if isinstance(value, float):
        value = round(value, 2)
    if isinstance(value, (list, tuple, set)):
        return ",".join(sorted(str(v).strip().lower() for v in value))
    return str(value).strip().lower()


def _hash(value):
    return hashlib.sha256(_normalize(value).encode()).hexdigest()[:16]


def check(name, value):
    """Stop with a hint unless `value` is the expected answer for `name`."""
    if _hash(value) != ANSWERS[name]:
        raise ValueError(
            f"❌ {name} = {value!r} is not right. "
            "Re-read the text above this cell and try again."
        )
    print(f"✅ {name}")


def check_score(name, value, actual):
    """Stop with a hint unless `value` is `actual` rounded to 2 decimals.

    For results that differ slightly between computers (e.g. k-NN ties).
    """
    if not isinstance(value, (int, float)) or abs(value - round(actual, 2)) > 0.005:
        raise ValueError(
            f"❌ {name} = {value!r} is not right. "
            "Read the score printed above and round it to 2 decimals."
        )
    print(f"✅ {name}")


def commit(prediction, options):
    """Record a prediction before seeing the result."""
    if prediction not in options:
        raise ValueError(f"Choose one of {options} first.")
    print(f"📌 Your prediction: {prediction!r}. Now run the next cell and compare.")

1. The dataset#

The data comes from the 1985 Current Population Survey (CPS), a survey of US workers. Each row is one person. The columns are:

column

meaning

EDUCATION

number of years of education

SOUTH

does the person live in the South of the US?

SEX

sex of the person

EXPERIENCE

number of years of work experience

UNION

is the person a member of a trade union?

WAGE

hourly wage, in dollars

AGE

age in years

RACE

race of the person

OCCUPATION

type of job

SECTOR

sector of activity

MARR

marital status

Our goal later in this module: predict whether a person earns more than $10 an hour from the other columns. The column we want to predict is the target.

3. Numerical or categorical?#

A column is numerical when its values are numbers that can be compared and averaged (for example 12 years of education is more than 8). It is categorical when its values are labels from a finite set (for example Management, Sales…).

➕ Going further: a suspicious relationship#

In the pair plot, the panel AGE vs EXPERIENCE (and to some extent AGE vs EDUCATION) looks very structured. Let us test an idea: maybe experience is simply computed as AGE - EDUCATION - (some constant).

(wages["AGE"] - wages["EDUCATION"] - wages["EXPERIENCE"]).value_counts()

✏️ For almost every person, AGE - EDUCATION - EXPERIENCE is the same number. Which one?

So for nearly everyone, EXPERIENCE = AGE - EDUCATION - 6: people are assumed to start school at 6 and to work as soon as they leave school. EXPERIENCE was computed by the survey, not measured.
