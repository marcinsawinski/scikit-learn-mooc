📒 Workbook M1.02 — Predicting high wages from numbers#

In the lab we trained our first models on the numerical columns of the adult census, scaled the data, built a pipeline and used cross-validation. In this workbook you do the same on the 1985 wages survey, and you will see what happens when the units of a feature change.

How this workbook works

  • The code is written for you. You do not need to write code, but you need to understand every step.

  • Every ____ is a gap. Fill it in with the value asked for in the text above the cell. The error NameError: name '____' is not defined means: a gap is still empty.

  • check(...) tells you whether your value is right (✅) or stops with a hint (❌).

  • commit(...) records a prediction before you see the result. Be honest: a wrong prediction costs nothing, it is how you learn.

  • Questions marked 🧠 Think are not checked here. You will need the answers for the Moodle quiz and for the discussion at the start of the next lab.

import hashlib
import warnings

warnings.filterwarnings("ignore", category=FutureWarning)

ANSWERS = {
    "dominant_feature": "013f54400c82da08",
    "dummy_accuracy": "18db98e3760ea465",
    "logreg_accuracy": "5ecbc825ba5c1685",
    "n_train": "26d228663f13a885",
    "numerical_features": "8809d6cbbcfd05bc",
    "slower_version": "9322efcf93952a27"
}

def _normalize(value):
    if isinstance(value, float) and value.is_integer():
        value = int(value)
    if isinstance(value, float):
        value = round(value, 2)
    if isinstance(value, (list, tuple, set)):
        return ",".join(sorted(str(v).strip().lower() for v in value))
    return str(value).strip().lower()


def _hash(value):
    return hashlib.sha256(_normalize(value).encode()).hexdigest()[:16]


def check(name, value, hint="Re-read the text above this cell and try again."):
    """Stop with a hint unless `value` is the expected answer for `name`."""
    if _hash(value) != ANSWERS[name]:
        raise ValueError(f"❌ {name} = {value!r} is not right. {hint}")
    print(f"✅ {name}")


def check_score(name, value, actual):
    """Stop with a hint unless `value` is `actual` rounded to 2 decimals.

    For results that differ slightly between computers (e.g. k-NN ties).
    """
    if not isinstance(value, (int, float)) or abs(value - round(actual, 2)) > 0.005:
        raise ValueError(
            f"❌ {name} = {value!r} is not right. "
            "Read the score printed above and round it to 2 decimals."
        )
    print(f"✅ {name}")


def commit(prediction, options):
    """Record a prediction before seeing the result."""
    if prediction not in options:
        raise ValueError(f"Choose one of {options} first.")
    print(f"📌 Your prediction: {prediction!r}. Now run the next cell and compare.")

3. A first model: nearest neighbours#

A k-nearest neighbours classifier predicts the class of a person by looking at the k most similar people in the training set and taking the majority answer. “Similar” means close in distance, computed from the feature values.

✏️ Use 15 neighbours.

from sklearn.neighbors import KNeighborsClassifier

knn.fit(data_train, target_train)
knn.score(data_test, target_test)

score gives the accuracy on the test set: the share of people for whom the prediction is right.

5. ➕ Going further: what if the units change?#

Imagine that the HR system we got the data from stores the age in days instead of years. Nothing else changes: same people, same information.

data_train_days = data_train.assign(AGE=data_train["AGE"] * 365)
data_test_days = data_test.assign(AGE=data_test["AGE"] * 365)
data_train_days.head()

🔮 Predict first. We train the same 15-neighbours model on this data. Will the test accuracy go “up”, “down”, or stay “the same” (compared to the score with age in years)?

my_prediction = ____
commit(my_prediction, ["up", "down", "the same"])

knn_days = KNeighborsClassifier(n_neighbors=15)
knn_days.fit(data_train_days, target_train)
knn_days.score(data_test_days, target_test)

✏️ Accuracy with age in days, rounded to 2 decimals. Compare it with the dummy model.

knn_days_accuracy = ____
check_score("knn_days_accuracy", knn_days_accuracy, knn_days.score(data_test_days, target_test))

Why? The model compares people with a distance: for each feature it takes the difference between two people, squares it, and adds everything up. Let us look at these squared differences for the first two people of the training set:

person_a, person_b = data_train_days.iloc[0], data_train_days.iloc[1]
pd.DataFrame(
    {"person A": person_a, "person B": person_b, "squared difference": (person_a - person_b) ** 2}
)

✏️ Which feature now decides almost alone who is “close” to whom?

dominant_feature = ____
check("dominant_feature", dominant_feature)

A difference of 20 years of experience counts 400 in the distance, while a difference of 20 years of age counts more than 53 million. The model effectively ignores education and experience.

The fix is to put all features on a comparable scale before computing distances. StandardScaler transforms each feature so that it has mean 0 and standard deviation 1. A pipeline chains the scaler and the model, so the scaling learned on the training set is reused on the test set.

🔮 Predict first. With the scaler, will the accuracy (still age in days) be “below the dummy”, “close to the original score”, or “far above the original score”?

my_prediction = ____
commit(my_prediction, ["below the dummy", "close to the original score", "far above the original score"])

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

scaled_knn = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=15))
scaled_knn.fit(data_train_days, target_train)
scaled_knn.score(data_test_days, target_test)

scaled_knn_days_accuracy = ____
check_score("scaled_knn_days_accuracy", scaled_knn_days_accuracy, scaled_knn.score(data_test_days, target_test))

Does the logistic regression care about units?#

🔮 Predict first. Logistic regression does not compute distances: it multiplies each feature by a weight, and can simply learn a weight 365 times smaller for age in days. Will its accuracy with age in days be “much lower”, “about the same” or “much higher” than 0.74?

my_prediction = ____
commit(my_prediction, ["much lower", "about the same", "much higher"])

logreg_days = LogisticRegression()
logreg_days.fit(data_train_days, target_train)
print("accuracy:", round(logreg_days.score(data_test_days, target_test), 3))

scaled_logreg_days = make_pipeline(StandardScaler(), LogisticRegression())
scaled_logreg_days.fit(data_train_days, target_train)
print("accuracy with scaling:", round(scaled_logreg_days.score(data_test_days, target_test), 3))

The accuracy hardly moves. But scaling still matters for this model: it finds its weights step by step (iterations), and badly scaled features make that search slower. n_iter_ tells how many iterations were needed:

print("iterations without scaling:", logreg_days.n_iter_[0])
print("iterations with scaling:   ", scaled_logreg_days[-1].n_iter_[0])

✏️ Which version needed more iterations? Write "without scaling" or "with scaling".

slower_version = ____
check("slower_version", slower_version)

On a dataset with thousands of features and millions of rows, this difference is the difference between seconds and hours, or a model that stops before it has converged.

6. One split is not enough: cross-validation#

Our test set holds only 134 people. With another random split, the scores could be different. Cross-validation repeats the train/test procedure on several splits and reports all the scores.

✏️ Use 5 splits (folds).

from sklearn.model_selection import cross_validate

cv = ____
data_days = data.assign(AGE=data["AGE"] * 365)
models = {
    "dummy": DummyClassifier(strategy="most_frequent"),
    "scaled knn": make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=15)),
    "scaled logreg": make_pipeline(StandardScaler(), LogisticRegression()),
}
results = {}
for name, model in models.items():
    scores = cross_validate(model, data_days, target, cv=cv)["test_score"]
    results[name] = scores
    print(f"{name:14s} {scores.round(2)}  mean {scores.mean():.2f} ± {scores.std():.2f}")

✏️ Mean cross-validated accuracy of the scaled knn, rounded to 2 decimals:

cv_knn_accuracy = ____
check_score("cv_knn_accuracy", cv_knn_accuracy, results["scaled knn"].mean())
